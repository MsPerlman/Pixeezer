# Pixeezer

Personal fork of [Pixer](https://github.com/Minuga-RC/Pixer), an unofficial Deezer client for
Android — which is itself a fork of [PixelPlayerOSS](https://github.com/lostf1sh/PixelPlayerOSS).

This is a hobby project for my own use: tweaks, experiments, and fixes on top of Pixer, kept in
sync with upstream where it makes sense. Not affiliated with or endorsed by Deezer.

## Where the code is

The Android app itself lives in [`Pixer-master/`](Pixer-master), along with its own README,
license, and contributor docs.
